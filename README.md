Экобот 
Автор Мирон
Телеграм бот, который может помогает с экологией 

Цель проекта: Помочь узнать о глобальным потеплением и советах по борьбе с ним.

Что может бот: Играть в мини игры (бета) , давать советы по борьбе с глобальным потепленим , расказывать факты и что такое глобальное потепление

Возможно скоро появится больше мини игр
